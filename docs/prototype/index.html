牛备 NiuBackup · 界面设计稿

手机照片与文件，经私有组网直连备份到自己电脑的产品。这一稿先定视觉语言，再给手机端与桌面端的样机——本页全部为静态样机，无真实功能，确认方向后再照此写代码。本轮修订五点：备份新增暂停 / 继续，组网改为全自动、界面只显示网络状态，文件库与记录改为分页加载，新增扫码登录——手机已登录时扫电脑端二维码即可登录电脑，同账号设备自动组同一网络、无需再填网络参数或手动配对；并取消授权期限——产品开源免费，注册即永久可用，不设试用与到期。

设计语言

一套令牌（颜色、字阶、圆角、间距）同时驱动手机端和桌面端，两端看起来必须是同一个产品。主色取深青蓝——沉稳、可信、像「保管」；点缀用牛系的琥珀橙，只出现在行动按钮、进度高点和待处理提醒上，不铺张。

分页规则（文件库与记录统一 · 本轮新增）

卡顿的根源是一次把几千条全渲染出来。改为分页后：列表只向本地 SQLite 索引按页查询（LIMIT / OFFSET），首屏只建当前页的视图，翻页才换下一批；总数与页码常驻，筛选条件变化时回到第 1 页。

文件库
手机文件库 · 每页 48 项

3 列网格一页 48 项（约 16 行缩略图），6,269 项共 131 页。翻页只解码本页缩略图，不预加载全库。

记录
手机记录 · 每页 20 条

按日分组在页内呈现，跨页时日期组头在新页重复出现，不出现「半组」记录。5,412 条共 271 页。

桌面记录
桌面备份记录 · 每页 50 条

左列列表分页、右列预览只跟随当前页的选中项；支持页码直跳与每页条数标识。5,412 条共 109 页。

翻页行为
不做无限滚动 · 不一次全量加载

用明确的上一页 / 页码 / 下一页，而不是滑到底自动灌入——页数可预期、滚动位置可恢复，低端机也不会越滑越卡。

扫码登录与同账号组网（本轮新增）

核心规则只有一句：账号即网络。不再让用户记网络名、密钥或服务地址——谁登录了同一个账号，谁就自动进同一个专属网络（nb-xxxx），登录完成即组网完成。

1
电脑端出码

电脑端打开登录页默认就是「扫码登录」：显示一次性二维码（2 分钟有效、过期自动刷新），旁边写清用哪台手机扫。密码登录收进同一张卡的页签，随时可切。

2
手机扫码确认

手机已登录时，从「我的 → 扫码登录电脑」或备份页扫码入口打开扫码框；扫到后不直接放行，先弹确认页：显示电脑名称 / 系统 / 申请时间，核对无误点「确认登录」才放行。

3
同账号自动同网

确认后电脑端以同一账号完成登录并登记为该账号的设备，服务端下发该账号的专属网络凭证，两端自动加入同一网络并开始发现彼此——全程不出现网络名、密钥、IP 输入框。

安全边界
二维码一次性 · 手机端二次确认

二维码只含一次性登录票据，不含账号密码；截图转发无效、用过即废。手机不在手边时，电脑端仍可用账号密码登录，两条路登录的是同一个账号、进同一个网络。

与旧配对的关系
同账号 = 已信任，取消批准环节

扫码登录本身就是账号持有者在手机上的确认，这台电脑直接以同账号入网，不再走任何批准步骤；未登录同账号的设备根本进不了这个网络，也就不存在待批准队列。

状态可见
电脑端三态：待扫码 → 已扫码待确认 → 已登录

手机一扫，电脑端二维码立刻变「已扫码，请在手机上确认」；手机点确认后电脑端自动进主界面，不用刷新、不用再点登录。

02

手机端 · 四个页面 + 暂停状态、播放预览与扫码确认

底部导航固定四页，与功能一一对应，不再把所有东西堆在一个调试屏上。每页只做一件事：备份页管「现在传」，文件库管「哪些已备、哪些能删」，记录页管「PC 上有什么」，我的页管账号与设置。本轮修订四点：一、备份可暂停——备份中进度卡下常驻「暂停备份」大按钮，暂停后进入已暂停状态（另附一屏），点「继续备份」从断点续传；二、组网全自动——App 自己完成组网，界面任何一页都不给组网开关和参数入口，只常驻展示网络状态（已连接 · 直连 / 等待直连）；三、文件库与记录分页——文件库每页 48 项、记录每页 20 条，列表底部常驻分页器（上一页 / 当前页·总页数 / 下一页），只渲染当前页，不再一口气铺满几千条；四、扫码登录电脑——「我的」页新增「扫码登录电脑」入口，手机已登录时扫电脑端二维码、在手机上确认一次，电脑端即以同一账号登录并自动加入同一网络（另附扫码确认一屏）。另有从记录与文件库点开的视频播放页与照片预览页两屏沉浸页，不占底部导航，是内容的详情层。

03

桌面端 · 侧边栏主窗

桌面端放弃单窗口堆控件的老结构：左侧深青蓝导航栏固定六个分区，右侧只显示当前页。导航栏同时是品牌面——字标、当前账号与「开源免费」标识都在这里，窗口任何一页都不会「不知道自己是谁的软件」。组网在桌面端同样全自动：引擎起来即组网，界面只在概览页展示网络状态，不设组网开关与参数页。备份记录与手机端一致分页：每页 50 条，只渲染当前页。登录默认扫码：登录页第一页签就是二维码——手机已登录时扫码 + 在手机上确认一次即完成登录、设备登记与组网三件事；没有手机在手边时切到「账号密码」页签走老路，登进的是同一个账号、同一个网络。
